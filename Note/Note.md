**Phân loại hệ thống thông tin (Information System Types)** — gồm 4 loại chính:

| Loại hệ thống      | Tên đầy đủ                    | Chức năng chính                                                              | Đối tượng sử dụng                  |
| ------------------ | ----------------------------- | ---------------------------------------------------------------------------- | ---------------------------------- |
| **TPS**            | Transaction Processing System | Ghi nhận, xử lý các **giao dịch hàng ngày** (bán hàng, nhập kho, hóa đơn...) | Nhân viên nghiệp vụ                |
| **MIS**            | Management Information System | Tổng hợp, báo cáo dữ liệu từ TPS để hỗ trợ **quản lý, giám sát hoạt động**   | Quản lý cấp trung                  |
| **DSS**            | Decision Support System       | Phân tích, mô phỏng, hỗ trợ **ra quyết định bán cấu trúc**                   | Nhà quản lý, chuyên viên phân tích |
| **EIS** (hoặc ESS) | Executive Information System  | Hệ thống cấp cao, cung cấp **tổng quan chiến lược, biểu đồ, chỉ số KPI**     | Ban giám đốc, CEO                  |
